# Coding Agent Adapters

Un Adapter conecta un coding agent con el Agentic Core.

Debe:
1. hacer que el agente lea `AGENTS.md` y la Policy efectiva;
2. conservar la jerarquía autoritativa del Core;
3. respetar Human Gates;
4. escribir cambios en el repositorio real del proyecto;
5. ejecutar verificaciones permitidas;
6. producir Evidence antes de `Done`.

No puede cambiar requisitos, ampliar permisos ni saltarse Gates.
