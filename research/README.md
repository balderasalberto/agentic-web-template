# Research System

## Propósito

Este directorio mantiene el mecanismo de investigación y evolución del Agentic Web Template.

La investigación diaria puede detectar nuevas prácticas, herramientas o patrones, pero **no modifica automáticamente el template**.

## Flujo de evolución

```text
Research Radar
      ↓
Finding
      ↓
Relevance Assessment
      ↓
Impact Assessment
      ↓
Adopt / Experiment / Reject / Defer
      ↓
Decision
      ↓
Change Proposal
      ↓
Human Gate when required
      ↓
Implement
      ↓
Test / Eval
      ↓
Update Template
```

## Regla

Una novedad no se incorpora solo porque sea nueva o popular. Debe demostrar beneficio para eficiencia, agilidad, calidad, seguridad o mantenibilidad.

## Archivos

- `radar.md` — formato y registro de hallazgos.
- `decisions.md` — decisiones sobre adoptar, experimentar, rechazar o posponer.
- `archive/` — histórico de investigaciones cerradas.

## Relación con la tarea programada

El Radar Agentic Engineering puede producir hallazgos diarios que posteriormente se evalúan contra este proceso.
